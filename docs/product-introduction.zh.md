# Sykes Pennystock Radar — 中文产品说明

## 一、这个 repo 是什么

**Sykes Pennystock Radar** 是一个 Agent Skill。

它把 Timothy Sykes 的仙股交易方法论，蒸馏成一套可重复的“筛选 → 评分 → 判断”流程。

你给一个标的，它会告诉你：

| 输出什么 | 什么意思 |
|---|---|
| ✅ **Buyable** | 目前符合入场条件，可做 |
| 👀 **Watchlist Only** | 条件不够，先看着别动 |
| ❌ **Avoid** | 该放弃就放弃 |

不止结论。
它还会告诉你：

- 这票现在处在 **7 步框架**的哪一步
- **PREPARE 评分**是多少，每个维度是强、中、弱
- 入场 / 失效 / 出场位置在哪里
- 这只票更适合 **追涨**、**恐慌接多**，还是根本不该碰

**这不是预测。这是一个交易过滤器。**

## 二、为什么要做这个技能

美股小票最难的，从来不是“有没有涨过”。

最难的是你不知道它现在处在哪个阶段。

很多票看起来都像机会：

- 有催化剂
- 有新闻
- 有社交讨论
- 有大波动
- 还有人发截图说自己赚了

但真正的问题是：

1. 它现在是在启动前，还是已经拉完了？
2. 它是还能接，还是只剩下最后一口气？
3. 它到底有没有流动性，能不能进也能不能出？
4. 它是有故事，还是只有故事感？

Sykes Pennystock Radar 就是为了解决这 4 个问题。

它不是一个“会涨”预测机。
它是一个“现在值不值得做”判断器。

## 三、它靠什么判断

### 3.1 7 步框架

任何一支仙股，都会在下面 7 个阶段里循环：

| 阶段 | 中文 | 意味着什么 |
|---|---|---|
| #1 Pre-Pump | 预泵期 | 聪明钱低调进场，社交媒体开始铺垫 |
| #2 Ramp | 加速期 | 成交量放大，聊天室开始密集讨论 |
| #3 Supernova | 超新星爆发 | 放量暴涨，散户最好赚钱的阶段 |
| #4 Cliff Dive | 悬崖跳水 | 炒作结束，急跌 50%+ |
| #5 Dip Buy | 恐慌接多 | 急跌到恐慌低点，等反弹 |
| #6 Dead Pump Bounce | 死泵反弹 | 最后一哆嗦，空间有限 |
| #7 Long Kiss Goodnight | 长吻晚安 | 慢慢跌回起点，归零 |

**最关键的两个位置：Supernova（#3）和 Dip Buy（#5）。**

### 3.2 PREPARE 评分量表

每个标的会从 7 个维度打分：

| 字母 | 维度 | 在问什么 |
|---|---|---|
| **P** | Pattern / Price | 形态对不对？现在什么阶段？ |
| **R** | Reason | 为什么涨？催化剂够不够硬？ |
| **E** | Ease of Entry / Exit | 流动性够不够？ |
| **P** | Past Performance | 以前遇到同类催化剂怎么走？ |
| **A** | Agenda / timing window | 时间窗口还在不在？ |
| **R** | Risk / Reward | 值不值得赌？至少 1:3 |
| **E** | Environment | 大环境配不配合？ |

每一项都会被标成 **强 / 中 / 弱**，最后汇总成一个可交易性判断。

### 3.3 三条铁律

1. **快速止损**  
   单笔亏损不能拖成大亏。

2. **逢强卖出**  
   分批止盈，别把纸面利润全送回去。

3. **绝不加仓亏损**  
   只加仓已经证明方向对的仓位。

## 四、这个技能怎么操作

你可以把它当成一个“交易版门禁系统”。

### 单票模式

你给我一个 ticker，比如：

- `ASTC`
- `PAVS`
- `INHD`
- `EDHL`
- `STI`

我会按这个顺序判断：

1. 它现在处在哪个阶段
2. PREPARE 分数是多少
3. 是 `Buyable`、`Watchlist Only` 还是 `Avoid`
4. 如果能做，应该怎么进
5. 如果做错了，哪里是失效点
6. 这票更像追涨、接多，还是不该碰

### 观察名单模式

你给我一个名单，我会直接帮你排序：

1. 哪些最值得研究
2. 哪些是能盯的
3. 哪些可以直接忽略

### 美股小票池模式

如果你丢给我一批小票，我会先按以下顺序筛：

1. 催化剂新不新
2. 流动性够不够
3. 浮动盘紧不紧
4. 现在是不是启动段
5. 风险回报值不值得

这样你不用自己在一堆票里瞎翻。

### Agent 示例

所以我把这套 PREPARE 方法论蒸馏成了 Agent Skill。

它能帮你自动筛选符合条件的标的。

比如你说 `"$ASTC"`，Agent 可以给出这种结构化判断：

- 形态：进入 `Supernova` 爆发期（模式 #3）✅
- 流动性：日均成交量达标 ✅
- 催化剂：有新闻驱动（合同 / 合作）✅
- 历史表现：过去同类模式下表现一致 ✅
- 风险回报：当前入场点距止损 8%，目标利润 30%+（1:4）✅

结论：

> 符合入场条件。建议小仓位，设 8% 止损，分批止盈。

这类输出的重点不是替你预测，而是把“能不能做、怎么做、错了怎么退”先说清楚。

## 五、它的判断标准是什么

这个技能不会用“公司好不好”来做第一判断。

它更看这些：

- 是不是低浮动
- 有没有异常成交量
- 有没有新的故事或新闻
- 现在是不是还在能交易的阶段
- 是不是容易被 squeeze
- 是不是已经太晚

如果一只票：

- 没催化剂
- 没流动性
- 已经太晚
- 风险回报很差

那它就应该直接被打到 `Avoid` 或 `Watchlist Only`。

## 六、实战案例

### 案例 1：ASTC → Buyable

```
形态：Supernova 爆发期 (模式 #3)    ✅
流动性：日均成交量达标              ✅
催化剂：有新闻驱动（合同/合作）      ✅
历史表现：过去同类模式下表现一致      ✅
风险回报：距止损 8%，目标 30%+ (1:4) ✅

Verdict：Buyable
建议：小仓位，设 8% 止损，分批止盈
风格：恐慌接多 / momentum chase
```

### 案例 2：PAVS → 还能做，但不能乱追

如果一只票已经涨了一大段，但还在高位持续放量，故事还没讲完，那它可能还是能做的。

这种时候更重要的不是“还能不能涨”，而是：

- 现在是不是还在可交易区间
- 你是该追，还是该等回踩
- 有没有分批止盈的空间

### 案例 3：INHD → 典型快票

如果一只票波动极大，涨得很猛，但流动性和风险也极端，那它就不是“稳票”，而是“快票”。

这类票能做，但不能恋战。
你要的是交易节奏，不是信仰。

### 案例 4：EDHL → 启动前盯量能

如果一只票在启动前就出现了量能异动、社交热度上升、盘面开始被盯住，那它就可能进入 `Ramp`。

这时技能会更关注：

- 它有没有继续加速的条件
- 它是不是还没到最热的时候
- 现在进场是不是性价比最高的那段

## 八、最后一句话

这个技能不是让你永赚。

它是帮你少做三件事：

1. 在不该追的时候硬追
2. 在已经结束的时候还幻想
3. 在没有流动性的票里死扛

它的目标很简单：

> 让你更早知道一只票现在到底值不值得看，值不值得做，值不值得继续拿。

如果你只记住一句话，那就是：

**交易不是看到就买，而是看到之后先判断它现在到底是哪一段。**
