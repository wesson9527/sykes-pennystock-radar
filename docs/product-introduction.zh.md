# Sykes PennyStock Radar

## 1. 它是什么

Sykes PennyStock Radar 是一个面向仙股和高波动小盘股的尽调 Skill。

你给它一个 ticker、观察名单，或者一个美股小票池，它会帮你判断当前处于炒作周期的哪一步，给 PREPARE 打分，然后输出一个能不能看的结论。

## 2. 它解决什么问题

大多数小票筛选要么太空，要么太机械。

这个项目想放在中间：
- 不是基本面估值模型
- 不是无脑追涨机器人
- 是一个交易可行性过滤器

## 3. 核心方法

这个项目使用：
- 7 步生命周期
- PREPARE 过滤器
- 弱条件止损规则

## 4. 输出什么

单票输入时：
- verdict
- stage
- PREPARE score
- entry / invalidation / exit
- position note

扫描输入时：
- 排名候选
- 每只票最合适的阶段
- 忽略名单
- 需要时给 A / B / C 分层

## 5. 适合什么场景

- 美股仙股
- 高波动小盘股
- 催化剂驱动票
- 恐慌回调接票
- 逢强卖出策略

## 6. 不适合什么

- 长期投资
- 纯基本面判断
- 没有催化剂的票
- 流动性太差、进出不方便的票
