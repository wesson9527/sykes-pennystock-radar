# Sykes Pennystock Radar

## 1. 为什么会有这个技能

美股小票这件事，最难的从来不是“有没有涨过”。
最难的是你根本不知道它现在处在哪个阶段。

很多票看起来都像机会：

- 有催化剂
- 有新闻
- 有社交讨论
- 有大波动
- 还有人发截图说自己赚了

但真正的问题是：

1. 它现在是在启动前，还是已经拉完了？
2. 它是还能接，还是只剩下最后一口气？
3. 它到底有没有流动性，能不能进也能不能出？
4. 它是有故事，还是只有故事感？

Sykes Pennystock Radar 就是为了解决这个问题。

它不是来告诉你“这票一定涨”。
它是来告诉你：

> 这只票现在值不值得继续看，值不值得进，进了之后该怎么活着出来。

## 2. 这个技能的逻辑是什么

这套技能来自 Timothy Sykes 的方法论。

他的核心思路不是找好公司，而是找好交易：

- 低浮动
- 高波动
- 有催化剂
- 有热度
- 有炒作周期
- 有足够流动性

他看的是票的“情绪寿命”，不是票的“公司寿命”。

所以这个技能的逻辑也很简单：

### 第一层：判断这票有没有资格进场

先看三个最重要的东西：

- 有没有催化剂
- 流动性够不够
- 现在是不是已经太晚

如果这三个里有一个很差，那就先别冲。

### 第二层：判断它处在哪个阶段

一只仙股通常会走过 7 个阶段：

1. 预泵期
2. 加速期
3. 超新星爆发
4. 悬崖跳水
5. 恐慌接多
6. 死泵反弹
7. 长吻晚安

这个技能的核心，不是猜它明天涨不涨，而是判断它现在更像哪一段。

### 第三层：用 PREPARE 过滤器打分

PREPARE 是七个维度：

- Pattern / Price
- Reason
- Ease of Entry / Exit
- Past Performance
- Agenda / timing window
- Risk / Reward
- Environment

它本质上是在问：

- 这票的形态对不对
- 这票为什么动
- 进出方不方便
- 以前是不是也这么走过
- 现在是不是合适的时间
- 值不值得赌
- 大环境配不配合

每个维度都给强、中、弱，然后综合出一个结论。

## 3. 这个技能怎么操作

你可以把它当成一个“交易版门禁系统”。

### 单票模式

你给我一个 ticker，比如：

- `ASTC`
- `PAVS`
- `INHD`
- `EDHL`
- `STI`

我会按这个顺序判断：

1. 它现在处在哪个阶段
2. PREPARE 分数是多少
3. 是 `Buyable`、`Watchlist only` 还是 `Avoid`
4. 如果能做，应该怎么进
5. 如果做错了，哪里是失效点
6. 这票更像追涨、接多，还是不该碰

### 观察名单模式

你给我一个名单，我会直接帮你排序：

1. 哪些最值得研究
2. 哪些是能盯的
3. 哪些可以直接忽略

### 美股小票池模式

如果你丢给我一批小票，我会先按以下顺序筛：

1. 催化剂新不新
2. 流动性够不够
3. 浮动盘紧不紧
4. 现在是不是启动段
5. 风险回报值不值得

这样你不用自己在一堆票里瞎翻。

### Agent 示例

所以我把这套 PREPARE 方法论蒸馏成了 Agent Skill。

它能帮你自动筛选符合条件的标的。

比如你说 `"$ASTC"`，Agent 可以给出这种结构化判断：

- 形态：进入 `Supernova` 爆发期（模式 #3）✅
- 流动性：日均成交量达标 ✅
- 催化剂：有新闻驱动（合同 / 合作）✅
- 历史表现：过去同类模式下表现一致 ✅
- 风险回报：当前入场点距止损 8%，目标利润 30%+（1:4）✅

结论：

> 符合入场条件。建议小仓位，设 8% 止损，分批止盈。

这类输出的重点不是替你预测，而是把“能不能做、怎么做、错了怎么退”先说清楚。

## 4. 它的判断标准是什么

这个技能不会用“公司好不好”来做第一判断。
它更看这些：

- 是不是低浮动
- 有没有异常成交量
- 有没有新的故事或新闻
- 现在是不是还在能交易的阶段
- 是不是容易被 squeeze
- 是不是已经太晚

如果一只票：

- 没催化剂
- 没流动性
- 已经太晚
- 风险回报很差

那它就应该被直接打到 `Avoid` 或 `Watchlist only`。

## 5. 举例说明

### 例子 1：`ASTC`

如果一只票像 `ASTC` 这种：

- 有新闻催化
- 成交量放大
- 形态开始进入超新星阶段
- 还能给出明确止损

那它就可能是一个 `Buyable`。

但前提是：

- 你不是在最后一根大阳线去追
- 你知道自己错了要在哪里走

### 例子 2：`PAVS`

如果一只票已经涨了一大段，但还在高位持续放量，故事还没讲完，那它可能还是能做的。

这种时候更重要的不是“还能不能涨”，而是：

- 现在是不是还在可交易区间
- 你是该追，还是该等回踩
- 有没有分批止盈的空间

### 例子 3：`INHD`

如果一只票波动极大，涨得很猛，但流动性和风险也极端，那它就不是“稳票”，而是“快票”。

这类票能做，但不能恋战。
你要的是交易节奏，不是信仰。

### 例子 4：`EDHL`

如果一只票在启动前就出现了量能异动、社交热度上升、盘面开始被盯住，那它就可能进入 `Ramp`。

这时技能会更关注：

- 它有没有继续加速的条件
- 它是不是还没到最热的时候
- 现在进场是不是性价比最高的那段

## 6. 最后一句话

这个技能不是让你永赚。

它是帮你少做三件事：

1. 在不该追的时候硬追
2. 在已经结束的时候还幻想
3. 在没有流动性的票里死扛

它的目标很简单：

> 让你更早知道一只票现在到底值不值得看，值不值得做，值不值得继续拿。

如果你只记住一句话，那就是：

**交易不是看到就买，而是看到之后先判断它现在到底是哪一段。**
